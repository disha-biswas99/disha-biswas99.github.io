Which URLs can be auto-fetched?
Works: public HTML pages, hosted PDFs, Google Docs published to web, Notion public pages, plain text/markdown URLs.
Doesn't work: Articulate / Rise / Storyline / Captivate share links, iSpring previews, anything behind login, JS-rendered single-page apps. These need paste mode below — open the module, copy slide text, paste it in.

How it works: PowerPoint files (.pptx) are parsed slide-by-slide automatically — each slide becomes a separate review unit with title and body content (including speaker notes). Word (.docx) and Excel (.xlsx) files are extracted as a single content block. After upload, the relevant tab opens automatically so you can review and edit before running QA.

Anthropic API key
Only needed if you download this file and run it outside claude.ai. Inside claude.ai, AI reviews work automatically with no setup. Your key is stored only in this browser session.
How to get an API key:
1. Go to console.anthropic.com/settings/keys
2. Sign in (or create a free account)
3. Click "Create Key" → copy the key (starts with sk-ant-api03-)
4. Paste it above and click Save

Cost: A typical QA review uses ~5,000–15,000 tokens of Claude Sonnet, costing roughly $0.02–$0.06 per review. Anthropic gives new accounts free credits.

For team deployment: for production use across your QA team, you'd want a small backend service that holds one shared API key, so individual users don't need their own. This standalone file is best for personal use and demos.
